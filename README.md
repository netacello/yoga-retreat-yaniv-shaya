# ריטריט יוגה בסיני עם יניב שיה, 28.10 עד 1.11.2026

דף נחיתה סטטי לריטריט. הדף מוגש דרך GitHub Pages:

https://netacello.github.io/yoga-retreat-yaniv-shaya/

## מבנה

- `index.html` הדף עצמו, עברית, RTL, ללא תלות בקבצים חיצוניים מלבד גופן.
- `img/eden/` צילומי עדן ביץ' קמפ, חוף אל מחש.
- `img/yaniv/` צילומי המורה.

## מה צריך להשלים לפני פרסום

1. בקובץ `index.html` להחליף את `972XXXXXXXXX` בכפתור ההרשמה במספר וואטסאפ אמיתי.
2. לאשר מול הקמפ את מחירי הארוחות ואת מחיר המונית מטאבה, ולעדכן בסעיף "איך מגיעים".
3. לאשר עם יניב את שעות התרגול בטבלת הלו"ז.

## מקורות לתמונות

- `eden_booking_*.jpg` מעמוד הקמפ באתר Booking.com (מזהה נכס eden-camp, נואיבה).
- `eden_001.jpg` מאתר nuweibabeach.com, עמוד Eden Camp.
- `eden_sinaivibes.jpg` מאתר sinaivibes.co.il, עמוד עדן ביץ' קמפ.
- `yaniv_shaya.jpg` מעמוד המורה באתר סטודיו גופאני (ambody.co.il).
- `yaniv_power_yoga_video.jpg` תמונה ממוזערת מסרטון היוטיוב "Power yoga - יניב שיה".

התמונות שייכות לבעליהן ומשמשות כאן לצורך הצגת הריטריט בלבד.
