# ריטריט יוגה בסיני עם יניב שיה, 28.10 עד 1.11.2026

דף נחיתה סטטי לריטריט. הדף מוגש דרך GitHub Pages:

https://netacello.github.io/yoga-retreat-yaniv-shaya/

## מבנה

- `index.html` הדף עצמו, עברית, RTL, ללא תלות בקבצים חיצוניים מלבד גופן.
- `img/yasmina/` צילומי קמפ יסמינה, חוף אל מחש.
- `img/yaniv/` צילומי המורה.

## מה צריך להשלים לפני פרסום

1. כפתור ההרשמה מפנה לוואטסאפ של יניב.
2. לסגור עם סבאח את מחיר המונית מטאבה לחוף, ולעדכן בסעיף "איך מגיעים".
3. לאשר עם יניב את שעות התרגול בטבלת הלו"ז.

## מקורות לתמונות

- `yasmina_*.jpg` צילומי אורחים של קמפ יסמינה (סבאח), חוף אל מחש, מתוך עמוד הקמפ באתר hushot.co.il.
- `yaniv_shaya.jpg` צילום של יניב, באדיבותו.
- `yaniv_power_yoga_video.jpg` תמונה ממוזערת מסרטון היוטיוב "Power yoga - יניב שיה".

התמונות שייכות לבעליהן ומשמשות כאן לצורך הצגת הריטריט בלבד.
